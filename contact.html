Common questions

常見問題

如何確認活動是否仍可報名？

請查看該活動頁所標示的活動日期、報名狀態與正式公告。已結束的活動不提供報名。

活動的講題、講者及地點在哪裡查看？

相關資訊應以該活動的正式活動頁為準。若頁面尚未完整呈現，代表資料仍待確認與補入。

新版網站是否已連接原有報名系統？

目前新版前端尚未連接 Google Apps Script 報名後端。待原始程式碼與 API 契約確認後，才會進行安全整合與測試。
